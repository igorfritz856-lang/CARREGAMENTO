# Roteiro de Implementação (90 dias)

## Fase 0 — Descoberta (Semana 1-2)

- Levantamento de processos existentes no Excel.
- Catálogo de macros por criticidade.
- Definição de escopo do MVP.

**Entregáveis**
- Mapa AS-IS.
- Lista de regras de negócio.
- Matriz de riscos e dependências.

## Fase 1 — Fundação técnica (Semana 3-4)

- Setup de repositórios (frontend, backend, infraestrutura).
- Configuração de padrão de código, lint e testes.
- Definição do esquema inicial do banco.

**Entregáveis**
- Estrutura base do sistema.
- Pipeline CI inicial.
- Ambiente de homologação.

## Fase 2 — MVP funcional (Semana 5-8)

- Cadastros essenciais.
- Motor de regras (primeiro bloco de macros convertidas).
- Dashboard operacional inicial.

**Entregáveis**
- API v1 com autenticação.
- UI com navegação por módulo.
- Relatório operacional principal.

## Fase 3 — Robustez e escala (Semana 9-11)

- Auditoria completa (quem alterou, quando, antes/depois).
- Perfis e permissões detalhadas.
- Otimização de desempenho.

**Entregáveis**
- Trilha de auditoria ativa.
- Perfis por papel de negócio.
- Métricas de performance e error tracking.

## Fase 4 — Go-live (Semana 12-13)

- Migração de dados validada.
- Treinamento de usuários.
- Plano de rollback e suporte assistido.

**Entregáveis**
- Sistema em produção.
- Guia de operação.
- Plano de evolução pós-go-live.

---

## Indicadores de sucesso

- Redução de retrabalho manual.
- Queda de inconsistência de dados.
- Tempo de processamento menor que no fluxo Excel.
- Aumento de rastreabilidade e governança.
